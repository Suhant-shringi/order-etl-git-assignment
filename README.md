# Interview Reflection Questions

## 1. What is the difference between the staging area and the local repository?

The staging area is a temporary space where changes are prepared before committing. The local repository stores the committed history of the project.

## 2. Why should Data Engineers not commit large datasets?

Large datasets increase repository size, slow down cloning and pulling, and make version control inefficient. Data Engineers should store only code and necessary configuration files in Git.

## 3. What is the purpose of a Pull Request?

A Pull Request is used to review, discuss, and validate changes before merging them into the main branch.

## 4. What is the difference between git pull and git push?

git pull downloads the latest changes from a remote repository to the local machine.

git push uploads local commits from the local repository to the remote repository.
